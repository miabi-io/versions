Miabi versions

Latest releases of Miabi and its components, read by Miabi's update check and the miabi CLI. Requests carry no identifying data.

  • /v1/index.json — every component
  • /v1/miabi/latest.json
  • /v1/agent/latest.json
  • /v1/runner/latest.json
  • /v1/gateway/latest.json
  • /v1/cli/latest.json
  • /schema/v1.json — JSON Schema

Disable the update check with MIABI_UPDATE_CHECK=false. Documentation
